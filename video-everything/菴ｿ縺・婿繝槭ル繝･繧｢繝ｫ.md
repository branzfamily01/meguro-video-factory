## このスキルでできること

`$video-everything` は、動画制作の一部分だけを処理するスキルではない。入力がURL、手元の動画、音声、記事、台本、画面収録、楽曲、またはテーマだけでも、必要な工程を組み合わせて完成物まで進める。

主な対応範囲:

- YouTube、TED、Threads/Xなどの断片から元動画を探す
- 公式・完全版・高画質の出典を照合する
- 許可された方法で動画と字幕を取得する
- 動画・音声を全文文字起こしする
- 60秒、90秒、3分、5分などへ正確に切り抜く
- 英語などの元音声を残し、日本語編集字幕を付ける
- トーク、インタビュー、セミナーをダイジェスト化する
- 画面収録を手順動画へ編集する
- 話者を残したまま章見出し、図解、強調表示を付ける
- 顔や個人情報を守る構成へ作り替える
- 9:16 Shorts、16:9 YouTube、正方形などへ再構成する
- 記事やメモから顔なし解説動画を作る
- 商品・Webサイト紹介動画を作る
- 楽曲からMV、歌詞動画、ビジュアライザーを作る
- Renoise／Seedanceで作った映像を編集・字幕・音まで仕上げる
- 複数動画を同じデザインで量産する
- 失敗したレンダーを、内容を変えずに復旧する
- 最終MP4を実ファイル検査して納品する

## 実績として含む範囲

このスキルは、インストール済みツールの一覧ではなく、完成済みCodexプロジェクトから抽出した制作パターンを基準に動く。

実績として登録されている代表パターン:

- SNS断片から公式フル動画を特定する
- TED・研究・金融・ADHD系の正確な3分ダイジェスト
- 長尺インタビューの「強い答えから始めて巻き戻す」編集
- 公式版で欠けた発言を、検証済み別ソースで補う
- 同じ原本から重複しない別テーマを作る
- ブラウザ／アプリ画面収録のチュートリアル化
- 顔や私的UIを見せない再編集
- Seedance／Renoiseの日本語ネイティブ音声動画
- 複数ショットの連続AI短編
- 10〜30本規模のデータ駆動型動画量産
- 音楽・歌詞動画
- 動画、字幕、文字起こし、編集可能スライドの一括納品

詳細な根拠は [proven-patterns.md](proven-patterns.md) に記録されている。

次は実績として扱わない:

- インストールされているだけの未使用機能
- 最終成果物がない試作
- 別の生成サービスに置き換えただけの類似経験
- Soraを使った動画制作実績

未実施の依頼へ挑戦する場合は、過去実績ではなく「新しい拡張」として扱う。

## 導入方法

### 1. スキルを配置する

配布された `video-everything` フォルダを、Codexのスキルディレクトリへ置く。

```text
${CODEX_HOME}/skills/video-everything/
```

`CODEX_HOME` を設定していない通常環境では次を使う。

```text
~/.codex/skills/video-everything/
```

配置後、新しいCodexタスクを開く。利用可能スキルに `video-everything` が表示されれば導入完了。

### 2. 推奨環境

最低限:

- Codex
- Node.js
- FFmpeg／ffprobe

制作機能を広く使う推奨構成:

- HyperFrames: 動画の設計、モーション、プレビュー、レンダー
- media-use: 文字起こし、字幕、音、素材処理
- renoise:video-download: 対応プラットフォームからの許可された取得
- renoise:director: 新しいAI映像生成
- seedance-jp-speaking-video: Seedanceの日本語発話動画

すべてが必須ではない。使えない機能があっても、ローカル処理と利用可能なツールで進められる範囲は継続する。

## 最短の使い方

依頼文の先頭でスキル名を指定する。

```text
$video-everything を使って、この動画から60秒の日本語字幕付きダイジェストを作って。
元音声は残す。16:9。BGMなし。プレビューを先に見せて。
```

素材を添付した場合:

```text
$video-everything で、この画面収録を初心者向けチュートリアルにして。
個人情報は映さない。3分以内。操作結果まで見せて。
```

URLだけの場合:

```text
$video-everything で、このURLの元動画と公式ソースを確認して、
重要部分を90秒に編集して。日本語字幕付き。
```

テーマだけの場合:

```text
$video-everything で、ADHDの「始められない」をテーマに
信頼できる一次動画を探し、60秒の横動画を1本作って。
```

## 依頼文の書き方

全部を指定する必要はない。最低限、次の3点があると速い。

1. 素材またはテーマ
2. 作りたい動画
3. 尺

より狙いを固定したい場合は、次の型を使う。

```text
$video-everything を使う。

入力:
目的:
視聴者:
掲載先:
尺:
縦横:
言語:
元音声:
字幕:
BGM:
顔・個人情報:
参考デザイン:
確認方法:
追加納品物:
```

記入例:

```text
$video-everything を使う。

入力: TEDのURL
目的: ADHDへの「怠け」という誤解を減らす
視聴者: 日本語の一般視聴者
掲載先: YouTube
尺: 60秒前後
縦横: 16:9
言語: 英語音声＋日本語字幕
元音声: 残す
字幕: 全編
BGM: なし
顔・個人情報: 話者の顔を図解で隠さない
確認方法: プレビューを先に見せる
追加納品物: 出典一覧
```

未指定項目は、掲載先、素材、過去実績から安全な初期値を選ぶ。

## 用途別コピペ例

### YouTube／TEDの切り抜き

```text
$video-everything で、この動画から一番重要な主張を60秒に切り抜いて。
発言をつなぎ替えて意味を変えない。元音声＋日本語字幕。16:9。
```

### 元動画を探してから編集

```text
$video-everything で、このThreads動画の元ネタを特定して。
公式フル版と一致確認した後、3分のダイジェストを作って。
使った時間範囲と出典も納品して。
```

### 過去動画と重複しない別テーマ

```text
$video-everything で、以前使った原本から別の60秒動画を作って。
過去のカット範囲と主張を比較し、未使用部分を優先して違う結論にして。
```

### 字幕だけ

```text
$video-everything で、この動画の映像と音声は変えず、
読みやすい日本語字幕だけ追加して。
```

### 画面収録のチュートリアル

```text
$video-everything で、この画面収録を2分の手順動画にして。
待ち時間と失敗操作は削除。クリック位置と結果は分かるように残す。
通知、タブ名、個人情報を確認して隠して。
```

### 9:16 Shorts

```text
$video-everything で、この横動画から45秒のShortsを作って。
単純な中央クロップではなく、人物と字幕を縦画面用に再配置して。
```

### 顔なし解説

```text
$video-everything で、この文章を60秒の顔なし解説動画にして。
抽象的なカード並びではなく、内容に合う図解と実例で見せて。
```

### 商品／Webサイト紹介

```text
$video-everything で、このサイトを30秒で紹介して。
実際の画面と操作結果を使い、機能一覧ではなく利用後の変化を見せて。
```

### 音楽・歌詞動画

```text
$video-everything で、この曲から歌詞動画を作って。
拍とセクションを解析し、歌詞は発音タイミングに合わせて。
```

### AI生成映像

```text
$video-everything で、Renoiseを使った30秒のAI短編を作って。
生成前に構成と必要クレジットを確認し、生成後はつなぎ目と音まで仕上げて。
```

日本語発話が必要な場合:

```text
$video-everything と $seedance-jp-speaking-video を使って、
日本語で話す15秒の縦型動画を作って。生成したネイティブ音声は残して。
```

### 複数本の量産

```text
$video-everything で、この表の10テーマを同じ番組デザインで動画化して。
各動画の主張と例は重複させず、1本ずつQAして。
```

## 制作中に行われること

依頼に応じ、次の工程から必要なものだけを実行する。

1. **素材検査**  
   尺、解像度、fps、映像・音声コーデック、回転、キーフレームを確認する。

2. **原本調査**  
   断片の話者、ロゴ、言葉、背景、公開日を照合し、公式ソースを探す。

3. **文字起こし**  
   公式字幕、プラットフォーム字幕、ローカル音声認識の順に適切なものを使う。

4. **編集方針**  
   完成動画が伝える一文を決め、完全な発言単位でカットを選ぶ。

5. **カットプラン**  
   入点・出点・使用尺を記録し、要求尺をフレーム精度で検証する。

6. **素材の正規化**  
   AV1、VFR、疎なキーフレームなどを必要に応じて編集向けH.264へ変換する。

7. **画面設計**  
   人物、既存字幕、ロゴ、重要UIを避け、一本の視覚言語で図解と字幕を置く。

8. **プレビュー検査**  
   冒頭、末尾、全編集点、長い字幕、人物位置、コントラスト、モーションを確認する。

9. **最終レンダー**  
   必要な承認後、指定解像度とfpsでMP4を作る。

10. **最終ファイルQA**  
    MP4を全尺デコードし、黒画面、フリーズ、無音、音ズレ、字幕欠けを検査する。

11. **納品**  
    最終動画、確認画像、出典、希望された字幕や文字起こしをまとめる。

## 確認・承認が必要な場面

次の場合は、Codexがいったん止まることがある。

- 有料のAI生成を開始する
- 公開、投稿、アップロード、送信を行う
- 素材の利用権や本人同意が不明
- 非公開ログインや個人情報へ触れる
- 指定サービスやモデルが使えず、別サービスへの変更が必要
- 利用する専門スキルが最終レンダー前のプレビュー承認を必須にしている

今回のHyperFrames制作のように、検査が通っていても最終MP4前にプレビュー承認を求める場合がある。

## 受け取れる納品物

基本:

```text
outputs/
├── project-final.mp4
├── project-contact-sheet.jpg
└── project-sources.md
```

希望に応じて追加:

- `.srt`／`.vtt` 字幕
- 全文・編集済み文字起こし
- サムネイル案
- 9:16、16:9、正方形の各版
- 音声なし／字幕なし版
- 編集可能なPowerPoint要約
- 使用範囲入りソース台帳
- 制作プロジェクト一式

「動画だけ」「素材一式も」など、必要な範囲を依頼文で指定できる。

## 修正の頼み方

タイムコードが分かれば添える。

```text
00:08の図解が元スライドにかぶっているので、一度消して。
```

感覚的な修正も可能:

```text
字幕をもう少し短く。
顔にかぶらないように。
BGMなしに戻して。
もっと具体的な重要ポイントへ構成し直して。
後半の結論を早く出して。
同じ原本だけど前回と重複しないテーマにして。
```

「もっと具体的」「別の重要ポイント」の場合は、タイトルだけでなく、文字起こしとカットプランへ戻って構成から変更する。

## 今回のADHD動画での実行例

依頼:

```text
1個、ADHD系の動画やってみて
```

実際に行ったこと:

1. 過去に使用したJessica McCabeのTEDx公式素材を確認した。
2. 既存3分版の使用範囲と比較した。
3. 未使用部分を中心に `14:42.571–15:42.675` の連続 `60.104秒` を選んだ。
4. 「始められないのは怠けではない」を一文の主張にした。
5. 発言順を変えず、連続区間のまま使用した。
6. 英語の元音声を残し、日本語編集字幕を19枚作った。
7. BGMと追加ナレーションを入れなかった。
8. 魚と海の比喩を使ったフィールドノート型の画面設計にした。
9. 話者の顔とTEDxの英語スライドを避けて図解位置を調整した。
10. レイアウト、モーション、字幕コントラストを検査した。

最終検査結果:

- レイアウト問題: 0
- モーション問題: 0
- コントラスト: 54/54合格
- プレビュー: 完成
- 最終MP4: 利用者の明示承認待ち

この例は、素材検索、過去編集との重複確認、発言単位の切り抜き、日本語字幕、画面設計、検査、プレビュー承認ゲートまでを示す。

## 制約と注意

- 技術的に取得できることと、公開利用できることは別。
- 外部素材を使う場合、出典と使用範囲を残す。
- 「著作権的に完全に安全」「許諾済み」と証拠なしに断定しない。
- 話者の発言を並べ替えて、本人が言っていない主張を作らない。
- ウォーターマークを出典隠しのために除去しない。
- 顔、氏名、通知、メール、決済、認証情報などを不用意に公開しない。
- 有料生成は、事前承認または既存の明示許可なしに開始しない。
- 外部への投稿・公開は、動画制作依頼だけから自動で推定しない。
- ネイティブ生成音声を、無断で別TTSへ置き換えない。
- 最終レンダーの成功メッセージだけで品質合格としない。

## トラブル時の見方

| 症状 | 対応 |
| --- | --- |
| 元動画が分からない | 特徴的な8〜20語、話者、セット、透かしから公式版を再検索する |
| ダウンロードが止まる | 中断ファイルを確認し、再開または適切な公式画質へ切り替える |
| シークすると映像が止まる | 短いキーフレーム間隔のH.264へ正規化する |
| AV1素材で確認が遅い | 元ファイルを保存したまま編集用H.264を作る |
| 字幕が顔やUIにかぶる | 時間ごとの人物位置を見て、図解を移動・短縮・一時非表示にする |
| フォントが変わる | フォントをローカル固定し、代表フレームを再確認する |
| レンダーが長時間で切れる | 編集を変えず、対応キャッシュ、分割、ハードウェアエンコードを使う |
| 最終MP4に黒画面・無音がある | 検出ログと実フレームを突き合わせ、意図した演出か不具合か判断する |
| AIショットがつながらない | 人物、場所、末尾フレーム、参照動画の連続条件を強化して再生成する |

詳しい制作判断は、同じフォルダ内の `routing.md`、`source-research.md`、`editorial.md`、`visual-audio.md`、`qa-recovery.md`、`delivery.md` を参照する。
